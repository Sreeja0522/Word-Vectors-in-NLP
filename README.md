# Word-Vectors-in-NLP

# Understanding Human Language with Word2Vec

* This project explores how computers represent and understand human language.
* It begins with one-hot encoding and the challenges of representing words numerically.
* Similarity measures such as cosine similarity are used to compare relationships between words.
* Word2Vec is then used to learn dense word embeddings from context.
* The learned embeddings place semantically related words closer together in vector space.
* Training dynamics are examined by observing how embeddings change to maximize context-word probabilities.
* Similarity matrices and vector visualizations help reveal the structure of the embedding space.
* Overall, it lays the foundation for understanding modern NLP techniques.
